# Skills, Sigils, and MCP Tools — BossForgeOS

**Skills:**
- Intrinsic, hard-coded abilities of an agent.
- Portable: can be learned from MCP tools, but only unlearned by trainer agents.
- Examples: code_analysis, github_integration, task_queue_management.

**Sigils:**
- Meta-agentic, permanent marks that grant advanced or mythic powers.
- Enable actions like reality rewrite, scroll fusion, or ritual override.
- Only removable by sigil-level power; both symbolic and practical.

**MCP Tools:**
- Dynamic, field-replaceable tools provisioned by the Forge or shared among agents.
- Can be added or removed at runtime, enabling new capabilities.
- Examples: model_invocation, web_search, documentation.

**Enforcement:**
- This distinction is codified in agent registration, documentation, and runtime logic.
- See also: Decrees_and_Governance.md, codemage_agent.py, BossGate_Abilities_and_Purposes.txt.
